# 北极星

Frostfall 是 **Warcraft III: The Frozen Throne** 的双模式：塔防是诺森德车道上的要塞，防守是英雄守护阵地。英雄是冠军，不是塔的皮肤。

Kingdom Rush、植物大战僵尸、气球塔防只作可读性的次要参考，不是主风格。不要画成可爱的手机塔防。

## 剪影层级

纯黑也能分开。身高（`BODY_PX`，再乘 `view.scale`）：

| 档 | 像素高 | 是什么 |
|---|---|---|
| Creep | 42 | 普通兵 |
| Elite | 56 | 精英 |
| Hero | 70 | 冠军，不低于精英 |
| Boss | 96 | 高于英雄 |
| Tower Lv1 / Lv2 / Lv3 | 60 / 76 / 92 | 建筑体量，不是又一个兵 |

Boss > Hero > Elite > Creep。塔随等级加高，脚仍然落在格子上。

英雄光只有活着的英雄：`#ffd68a`、线宽 3 的椭圆。倒下改 `#8b95a3`。怪和塔不描这圈。怪的法术圈是 `#7f9e92`。

## 诺森德

雪和岩石低饱和。威胁用高对比，不用糖果原色。职责色锁在 `DIRECTION.md` 的调色表里。

## 手机 / 微信小游戏

先服务手机触摸和帧时间，再考虑装饰。

- 触摸优先。没有悬停。建造、选中、放技能都要一次点按能完成。
- 目标 ≥60fps。120fps 走同一套函数，不另开一条重路径。
- 图是小 PNG、短序列（每段 2 帧）。不要大图集，避免解码卡顿。
- 播帧只做 Map 查找。不为每个单位分配画布。
- 预算紧的时候剪影优先于花哨特效。粒子不超过 `FX_LIMITS`：高档拖尾 3、命中 8、残影 12；低特效档拖尾 1、命中 4、残影 6。

## 这一批不做

关装饰后的路径色带、建造窗和战斗窗的 3 秒盲测、双经济与漏怪回流、等距遮挡超过四成时变透、小地图入侵箭头。选塔 / 选英雄命令互斥、英雄复活点标记、塔射程圈和英雄技能范围的不同画法、TD 英雄驻点与头像条已经在玩法里。

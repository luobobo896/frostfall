# 战场美术方向（P1）

对齐 `docs/game-design.md` §14.4–§14.6。这页只写**能执行的替换规则**：文件名和画布对了，运行时就换上；对不上就继续画 P0 剪影。不做动画，不写真 3D。

## 风格

- 西幻寒冰。地面用低饱和冷色，单位用更亮或更暖的两端（§14.5）。
- 光源固定**左上 45°**：亮面在左上，暗面在右下。不同光源的图不许混进同一屏。
- 投影是等距 2:1（`tile 64×32`，§14.1）。精灵只画这一个角度。
- `docs/art/art-*.png` 是概念参考。禁止把那些立绘原图 `drawImage` 进战场。

## 剪影（灰度下也要成立，和 P0 同一套）

- 箭塔 = 柱 + 三角顶。炮塔 = 矮墩 + 横炮管。冰塔 = 尖晶簇。电塔 = 杆 + 两侧电弧。Lv2 / Lv3 必须能看出多了一块，不能只改一个数字。
- 空中单位要有翼，翼比身体宽。重甲 / 攻城是块。死亡分裂是两个身体。光环是身体外的一圈。Boss 是尖刺星，画布比普通怪大。
- 英雄 = 头 + 身体 + 一把短武器（刀 / 杖 / 弓 / 锤）。
- **队伍色只画在底座环上**，不画进身体（§14.4）。四个玩家共用一张英雄图。

## 画布、文件名、锚点

| 键 | 文件 | 画布 |
|---|---|---|
| `towers/{id}_lv{1\|2\|3}` | `assets/towers/{id}_lv{n}.png` | 192×192 |
| `mobs/{id}_idle` | `assets/mobs/{id}_idle.png` | 普通 128²，精英 160²，Boss 256² |
| `heroes/{id}_idle` | `assets/heroes/{id}_idle.png` | 128×128 |
| `tiles/tile_a` `tile_b` `path` `swamp` `lava` | `assets/tiles/{name}.png` | 64×32 |

- 单位图的锚点是**底边中点**（脚）。脚以上画身体，底边不要留空行。
- 地块图铺满等距菱形，中心对齐格子中心，菱形外透明。
- 背景透明。不要在图里画血条、等级数字、队伍色环——那些仍由 `render.js` 画。
- **缺文件、加载失败、或等级对不上：画 P0 剪影。** 不许用 Lv1 顶替 Lv3，也不许用别的 id 顶替。
- 死亡英雄继续用灰色剪影。这批没有死亡帧。
- 工事箭塔复用 `towers/tw_arrow_lv1`。围墙仍用剪影。

## 这一批不做什么

只做上表里的**待机静帧**。走、攻、死亡、4 方向、10 个特效序列、地块角变体，都还不是这批的文件。以后加动作时再加后缀（例如 `_walk`），加载器现在只认上表。

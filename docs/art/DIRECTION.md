# 战场美术方向

对齐 `docs/game-design.md` §14.4–§14.6。文件名和画布对了，运行时就换上静帧；对不上就继续画 P0 剪影。动作和命中用程序图形，不新增序列帧，不写真 3D。

## 风格

- 西幻寒冰。地面用低饱和冷色，单位用更亮或更暖的两端（§14.5）。
- 光源固定**左上 45°**：亮面在左上，暗面在右下。不同光源的图不许混进同一屏。
- 投影是等距 2:1（`tile 64×32`，§14.1）。精灵只画这一个角度。
- `docs/art/art-*.png` 是概念参考。禁止把那些立绘原图 `drawImage` 进战场。

## 剪影（灰度下也要成立，和 P0 同一套）

- 箭塔 = 柱 + 三角顶。炮塔 = 矮墩 + 横炮管。冰塔 = 尖晶簇。电塔 = 杆 + 两侧电弧。Lv2 / Lv3 必须能看出多了一块，不能只改一个数字。
- 空中单位要有翼，翼比身体宽。重甲 / 攻城是块。死亡分裂是两个身体。光环是身体外的一圈。Boss 是尖刺星，画布比普通怪大。
- 英雄 = 头 + 身体 + 一把短武器（刀 / 杖 / 弓 / 锤）。
- **队伍色只画在底座环上**，不画进身体（§14.4）。四个玩家共用一张英雄图。

## 画布、文件名、锚点

| 键 | 文件 | 画布 |
|---|---|---|
| `towers/{id}_lv{1\|2\|3}` | `assets/towers/{id}_lv{n}.png` | 192×192 |
| `mobs/{id}_idle` | `assets/mobs/{id}_idle.png` | 普通 128²，精英 160²，Boss 256² |
| `heroes/{id}_idle` | `assets/heroes/{id}_idle.png` | 128×128 |
| `tiles/tile_a` `tile_b` `path` `swamp` `lava` | `assets/tiles/{name}.png` | 64×32 |

- 单位图的锚点是**底边中点**（脚）。脚以上画身体，底边不要留空行。
- 地块图铺满等距菱形，中心对齐格子中心，菱形外透明。
- 背景透明。不要在图里画血条、等级数字、队伍色环——那些仍由 `render.js` 画。
- **缺文件、加载失败、或等级对不上：画 P0 剪影。** 不许用 Lv1 顶替 Lv3，也不许用别的 id 顶替。
- 死亡英雄继续用灰色剪影。这批没有死亡帧。
- 工事箭塔复用 `towers/tw_arrow_lv1`。围墙仍用剪影。

## 剪影优先（换图前过一遍）

涂成纯黑也要分得开。不许只靠颜色区分：同形换色不算两种单位。

- 塔的职责和剪影绑死，不能互换。箭塔 = 柱 + 三角顶。炮塔 = 矮墩 + 横炮管。冰塔 = 尖晶簇。电塔 = 杆 + 两侧电弧。
- 路径靠两件事认出来：比可建地亮，并且有一圈硬边。只加亮、不加硬边，不算路径。
- 英雄比塔大一档，活着时有一圈暖色轮廓（`#ffd68a`）。这圈不是队伍色，塔不要画。

## 路径是单独的一层

- 路径格只用 `tiles/path`（缺图则填 `#6a7a90`）。硬边固定 `#141c28`、线宽 2.5，由渲染器描，不靠 PNG 的抗锯齿。
- `tile_a` / `tile_b` / 沼泽 / 岩浆用自己的软边。不许复用路径的填充色或这圈硬边，装饰块不能看起来能走。

## 射程圈

选中已建塔、预测放置、浏览器建造轮盘悬停某个塔种，以及小游戏建造面板**第一次点**某个塔种时，在该格地面画等距射程椭圆。深色底（线宽 5）加 `#fff4d2` 亮边（线宽 2），再加一层很淡的填色。不要用低透明度的绿线。

小游戏没有悬停：建造行第一下只预览射程，同一行再点一次才建造。

## 动作（程序算，不新增序列帧）

缺图时剪影也要动。`now === 0` 且冷却为 0 是静止姿势，和现有静帧对齐。

- 怪：走路起伏（空中幅度更大）。刚攻击时身体短促一沉。受击是两道斜线，不是变白。死亡离开逻辑列表后，画面上留不超过 0.42 秒的淡出，并收成一条横线。
- 塔：待命几乎不动。开火后坐按职责分开——箭塔向上一抽，炮塔向后一顿，冰塔晶体窜高，电塔两侧电弧张开。蓄力只出现在冷却末尾。影子和队伍色环不跟着后坐走。
- 英雄：待机轻起伏，攻击时朝前冲一截，死亡继续用灰色剪影（没有死亡静帧），身体压矮并加一条消散线。

加载器仍然只认待机静帧。走、攻、死亡不加 `_walk` 这类文件。

## 特效

弹道和命中靠形状分开，颜色只是辅助：

| 塔 | 弹道 | 命中 |
|---|---|---|
| 箭 | 开口箭头 | 叉 |
| 炮 | 封闭菱形 | 扁椭圆 |
| 冰 | 两颗小菱形 | 四颗菱形散开 |
| 电 | 折线 | 三道辐射 |

减速是怪身体外三颗菱形，随时间转，不是把身体涂蓝。

数量上限（`src/motion.js` 的 `FX_LIMITS`）：高档拖尾 3 段、命中残留 8、死亡残影 12；低档（设置里的低特效）拖尾 1、命中 4、残影 6。起伏仍算。不要为了特效去加运行时依赖。

## 这一批不做什么

待机静帧仍是上表那一套。不新增走、攻、死亡、4 方向或 10 条特效序列的文件，也不做地块角变体和真 3D。动作和命中是上面这些程序图形。

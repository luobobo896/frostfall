# 战场美术方向

北极星在 [`NORTH_STAR.md`](NORTH_STAR.md)。Frostfall 是 **Warcraft III: The Frozen Throne** 的双模式：塔防是诺森德车道要塞，防守是英雄守护。英雄是冠军，不是塔的皮肤。

Kingdom Rush、植物大战僵尸、气球塔防只作「小尺寸还能认出来」的次要参考，不是主风格。不要画成可爱的手机塔防。

对齐 `docs/game-design.md` §14.4–§14.6。文件名和画布对了就换上；对不上就画 P0 剪影。这一批是静帧加 2 帧短序列，不是真 3D，也不是 4 方向全身动画。

`docs/art/art-*.png` 是概念参考。禁止把那些立绘原图 `drawImage` 进战场。

## 手机 / 微信小游戏

先保证手机能摸、帧时间够用。浏览器是同一套画法，不是另一套更重的画面。

- 触摸优先，没有悬停。小游戏建造行第一下只预览射程，同一行再点一次才建造。
- 目标 ≥60fps。可选 120fps 走同一条函数（`poseClip` / `poseFrame` 是纯算术），不在每帧为每个单位分配画布。
- 资源是小 PNG。短序列每段两帧，单独文件，不打大图集，避免解码卡一下。
- 播一帧只查 Map（`resolveSprite`）。缺帧按下面的回退走，不临时拼图。
- 预算紧时剪影优先于粒子。特效密度遵守 `src/motion.js` 的 `FX_LIMITS`，低特效档再减半左右：高档拖尾 3、命中残留 8、死亡残影 12；低档拖尾 1、命中 4、残影 6。起伏仍算，不占这条预算。

## 剪影层级

涂成纯黑也要分得开。同形换色不算两种单位。跨职责的纯黑重叠（Jaccard，保住宽高比放进 48×48）不超过 30%。同一座塔的 Lv1/Lv2/Lv3、同一族 Boss 可以像，不拿来互相比。

身高是 `BODY_PX` 再乘 `view.scale`。Boss > Hero > Elite > Creep。英雄不低于精英。塔是建筑体量。

| 档 | `BODY_PX` | 除数 | 画出来的高度 |
|---|---|---|---|
| Creep | 42 | 2.5 | 半径 × 2.5 |
| Elite | 56 | 2.5 | 半径 × 2.5 |
| Hero | 70 | 2.6 | 半径 × 2.6 |
| Boss | 96 | 2.5 | 半径 × 2.5 |
| Tower Lv1 / Lv2 / Lv3 | 60 / 76 / 92 | 2.4 | 半径 × 2.4 |

`view.scale ≈ 0.74` 时英雄大约 52px 高，Boss 更高。

- 箭塔 = 细石柱 + 宽浅色三角顶。炮塔 = 矮石堡 + 横出的炮管。冰塔 = 矮基座 + 分开的细晶柱。电塔 = 短铁杆 + 两侧扁电弧。Lv2 / Lv3 必须多一块，不能只改一个数字。
- 食尸鬼是贴地的偏左身形加一只拖出去的爪。霜狼是扁长的一条。石像鬼的翼比身体宽，翼在上。沼泽巨魔是分开的两条腿加高肩。冰甲卫士是宽盾墙。蛛后是两个身体。巫妖是细袍加体外的一圈。Boss 是尖刺星，画布比普通怪大。
- 英雄 = 窄躯干 + 一把读得清的武器（刀 / 杖 / 弓 / 锤与盾）。四个英雄的剪影不能叠成同一个柱子。
- **英雄光只描在英雄上**：活着 `#ffd68a`、线宽 3；倒下 `#8b95a3`。怪、塔、工事都不描。怪的法术圈是 `#7f9e92`，不是金边。
- **队伍色只画在底座环上**，不画进身体。四个玩家共用一张英雄图。图里不画血条、等级数字。

## 诺森德调色

雪、石、木头低饱和。威胁靠形状和对比，不用糖果原色。光源固定左上。职责色和地形色与 `src/render.js` 一致；石、铁、木、雪是静帧里的辅色：

| 用途 | 色 |
|---|---|
| 背景 | `#070c14` |
| 可建地 A / B | `#10192a` / `#0c1522` |
| 路径 / 路径边 | `#6a7a90` / `#141c28` |
| 沼泽 / 岩浆 | `#1d3a2c` / `#5a2b1f`（岩浆边 `#e0a15c`） |
| 石 / 暗石 / 铁 / 木 / 雪 | `#3c4a5a` / `#24303c` / `#59636c` / `#6b5340` / `#d7e2ec` |
| 箭 / 炮 / 冰 / 电 | `#dbe6f2` / `#e0a15c` / `#79c8ee` / `#b98ce6` |
| 普通怪 / 精英 / Boss / 空中 | `#c9d6e6` / `#e8a33d` / `#d1503f` / `#9ad8ff` |
| 英雄光 / 怪的法术圈 | `#ffd68a` / `#7f9e92` |

## 画布、文件名、锚点

| 键 | 文件 | 画布 |
|---|---|---|
| `towers/{id}_lv{1\|2\|3}` | `assets/towers/{id}_lv{n}.png` | 192×192 |
| `towers/{id}_lv{n}_attack_{1\|2}` | 同目录 | 192×192 |
| `towers/{id}_lv{n}_death_{1\|2}` | 同目录 | 192×192 |
| `mobs/{id}_idle` | `assets/mobs/{id}_idle.png` | 普通 128²，精英 160²，Boss 256² |
| `mobs/{id}_walk_{1\|2}` `_attack_` `_death_` | 同目录，键里没有 `_idle` | 与静帧同尺寸 |
| `heroes/{id}_idle` | `assets/heroes/{id}_idle.png` | 128×128 |
| `heroes/{id}_walk_{1\|2}` `_attack_` `_death_` | 同目录 | 128×128 |
| `tiles/tile_a` `tile_b` `path` `swamp` `lava` | `assets/tiles/{name}.png` | 64×32 |

- 第 0 帧就是静帧，不另存 `_idle` 以外的休息姿势。塔没有走路帧。
- 单位锚点是**底边中点**（脚）。底边不要留空行。动作可以压扁、侧倾，不要把脚抬离底边。
- 地块铺满等距菱形，中心对齐格子，菱形外透明。路径硬边（`#141c28`，线宽 2.5）由渲染器描，不画进 PNG。
- **缺文件、加载失败、或等级对不上：画 P0 剪影。** 不许用 Lv1 顶替 Lv3，也不许用别的 id 顶替。
- 工事箭塔用门楼剪影（比 TD 塔矮，不复用 `towers/tw_arrow_lv1`）。围墙直段、转角、门洞仍用剪影。

## 播帧

`poseClip` / `poseFrame` 决定动作，`resolveSprite` 取图。热路径不分配画布。

| 状态 | 帧 |
|---|---|
| 待命、`now === 0` 的走路 | 0，静帧。程序起伏为 0 |
| 走路 | 6Hz，在第 1、2 帧之间。缺了回静帧 |
| 攻击 | `pulse ≥ 0.45` 用第 1 帧，`pulse > 0` 用第 2 帧，否则第 0 帧。缺了回静帧 |
| 死亡 | `deathT < 0.5` 第 1 帧，否则第 2 帧。**不回站立静帧**。两帧都缺就画剪影 |

死亡残影在画面上停 `DEATH_SEC`（0.42 秒）。已经画上动作帧时，不再叠程序脚步、后坐和塔的开火记号；蓄力记号在没摆姿势时仍画。影子和队伍色环留在原地。

塔防里沿路径走的怪算在移动，除非正在攻击。防守英雄只在 `path.length` 时走路。塔防英雄这一批仍原地待机或攻击，不在这批图里做驻点。

## 路径

路径格用 `tiles/path`（缺图则填 `#6a7a90`），并描上面的硬边。`tile_a` / `tile_b` / 沼泽 / 岩浆用自己的软边。装饰块不能看起来能走。

## 射程圈

选中已建塔、预测放置、浏览器建造轮盘悬停某个塔种，以及小游戏建造面板第一次点某个塔种时，在该格地面画等距射程椭圆。深色底（线宽 5）加 `#fff4d2` 亮边（线宽 2），再加一层很淡的填色。

## 特效

弹道和命中靠形状分开，颜色只是辅助：

| 塔 | 弹道 | 命中 |
|---|---|---|
| 箭 | 开口箭头 | 叉 |
| 炮 | 封闭菱形 | 扁椭圆 |
| 冰 | 两颗小菱形 | 四颗菱形散开 |
| 电 | 折线 | 三道辐射 |

减速是怪身体外三颗菱形，随时间转，不是把身体涂蓝。数量见上面的 `FX_LIMITS`。不要为了特效加运行时依赖。

## 这一批不做什么

- 4 方向、10 条特效序列、地块角变体、真 3D。
- 关掉装饰后，路径色带仍要读出入口到终点，以及入口出口的专用道具。
- 建造窗和英雄战斗窗的界面区分（3 秒盲测）。
- 双经济，以及漏怪扣命或回流在 HUD 上的画法。
- 等距遮挡超过约四成时，高塔和 Boss 变透或压低。
- 小地图：路径折线、英雄点、下一波入侵箭头。

重画静帧和短序列：`node tools/paint-stills.mjs`。
